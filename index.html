Bấm vào một mục để xem nội dung bên trong
Hướng dẫn tự sửa công việc trên GitHub
  1. Mở repository trên GitHub, chọn file index.html rồi bấm biểu tượng bút chì (Edit).
  2. Tìm cụm BẮT ĐẦU DỮ LIỆU CÔNG VIỆC ở gần đầu file. Chỉ cần sửa phần DU_LIEU_CONG_VIEC.
  3. Đổi ten để sửa tiêu đề, noiDung để sửa hướng dẫn, trangThai để đổi trạng thái. Muốn thêm cấp mới, thêm mục vào con: [ ... ].
  4. Bấm Commit changes. Nếu repository đã bật GitHub Pages, trang web sẽ được cập nhật sau khi triển khai.

Mẫu một mục công việc: Có thể sao chép khối sau và đặt trong một mảng con hoặc congViec.

{
  ten: "Tên công việc hoặc hướng dẫn",
  noiDung: `Dòng mô tả thứ nhất.
Dòng mô tả thứ hai.`,
  trangThai: "Chưa làm",
  con: [
    {
      ten: "Bước nhỏ hơn",
      noiDung: "Hướng dẫn cụ thể ở đây."
    }
  ]
},

Lưu ý: Có thể lồng các mục con nhiều cấp không giới hạn cố định. Giữ nguyên dấu ngoặc { }, dấu [ ] và dấu phẩy giữa các mục. Những thay đổi thực hiện khi xem trang chỉ là mở/thu gọn; muốn sửa nội dung công khai thì chỉnh file trên GitHub.
